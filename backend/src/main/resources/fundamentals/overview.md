# 📚 Fundamentals

> The core building blocks behind every interview — the language, the framework, and the ideas that tie them together.

Most interviews aren't won on exotic algorithms. They're won by clearly explaining **the everyday things** — how a `HashMap` works, why a Spring bean is a singleton, what `useEffect` actually does, or how Python handles async. This section is your friendly, plain-English guide to all of it.

Pick a track from the left. Each one starts with an **Overview** and then walks through focused topics you can read in a few minutes.

## 🌱 How to use this

- **Start with the Overview** of any track to get the lay of the land.
- **Read top to bottom** — topics are ordered from foundational to advanced.
- **Say it out loud.** If you can explain a concept in one plain sentence, you understand it.
- **Notice the trade-offs.** Interviewers rarely want "the answer"; they want to hear you weigh options.

## 💡 A mindset for interviews

> Depth beats breadth. Knowing *one* language deeply — how it stores data, manages memory, and handles errors — signals more maturity than name-dropping ten frameworks.
